# MINI FC27

Protótipo inicial de futebol 3D para navegador e Android.

## Como jogar
Abra `index.html` em um navegador com internet, ou publique o repositório com GitHub Pages (Settings → Pages → Deploy from a branch → main / root).

- Celular: joystick virtual para movimentar, PASSE e CHUTE.
- Computador: WASD/setas, E para passe, Espaço para chute.
- Reiniciar: zera o placar e reinicia o relógio.

## Estado atual
Primeira versão experimental: campo 3D, jogadores simples, adversários automáticos, bola, gols, placar e controles. Ainda não inclui regras completas, goleiros, carreira, licenças ou multiplayer. Requer internet para carregar Three.js via CDN.
